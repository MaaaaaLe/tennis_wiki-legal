# 이름결 — 성명학 기반 아기 이름 짓기

`index.html`을 브라우저로 열면 바로 동작하는 정적 웹앱입니다 (서버·빌드 불필요, GitHub Pages에서는 `/baby-name/`).

## 기능
- **이름 추천**: 성·성별·생년월일(양력/음력·윤달)·돌림자·꼭 넣을 음절을 입력하면 인기 이름 × 이름용 한자 조합을 모두 평가해 점수순으로 추천
- **이름 풀이**: 생각해 둔 이름의 한자를 직접 골라 성명학 풀이 확인
- **한자 고르기 도움**: 이름 풀이에서 이 이름에 사격·자원오행·획수 음양이 모두 좋은 한자에 👍, 사주의 용신·희신 기운 한자에 ! 표시. '선별 한자'(이름 다빈도·뜻이 무난한 한자)와 '인명 한자 전체' 전환
- **작명서**: 이름 풀이를 한 장으로 정리해 인쇄하거나 PDF로 저장
- **찜 목록**: 마음에 드는 이름 저장(브라우저 localStorage)

## 계산 방식과 검증
- **획수(원획법)**: 부수를 원래 글자 획수로 환산(氵→水 4, 艹→艸 6 …). 부수가 원형 그대로 쓰인 글자(泰·成 등)는 전체 획수를 사용. 작명서 원획 89자 기준표와 모두 일치.
- **자원오행**: 이름에 자주 쓰는 약 450자는 작명 관용값(`tools/overrides.py`), 나머지는 부수 기준, 부수로 정해지지 않는 글자는 발음오행으로 추정(화면에 `*`).
- **사주**: 태양황경으로 절기를 계산해 년·월주를 세움. 일·시주는 서울 진태양시(UTC+8:28) 기준(설정에서 끌 수 있음). 한국 서머타임(1948~1960, 1987~1988)과 UTC+8:30 시기(1954~1961) 보정.
- **음력 → 양력**: 삭(신월)과 중기를 천문 계산해 한국 표준시 기준으로 변환. 1950~2050년 전 날짜 왕복 변환 일치, 윤달(2033년 윤11월 포함)이 한국 달력과 일치.
- **용신**: 억부법(월지 가중치 2) + 조후 보정의 간이 판단. 신약이면 인성(재성이 많으면 비겁), 신강이면 식상(인성이 많으면 재성, 식상이 많으면 관성).

## 파일
- `engine.js` 계산 엔진(사주: 태양황경 기반 절기 계산, 4격, 오행, 추천)
- `names-data.js` 성씨·인기 이름·이름용 한자·81수리 표
- `hanja-data.js` 인명용 한자 8,094자 (자동 생성)
- `tools/overrides.py` 자원오행·획수 작명 관용 보정표 (값을 고친 뒤 `build_data.py` 재실행)
- `tools/verify.js` 정합성 검증 (`node baby-name/tools/verify.js`): 데이터 구조, 원획 기준표, 81수리, 4격 공식, 발음오행, 음력 왕복 변환·윤달, 사주 절입·일주 연속성·시주 경계, 점수 범위·추천 조건
- `tools/build_data.py` 데이터 생성 스크립트 — Unicode Unihan(@mandel59/mojidata 패키지) + libhangul hanja.txt

성명학은 학파마다 해석이 다른 전통 이론으로, 결과는 참고용입니다.
